# Contributing

Please open an issue for a substantial feature or compatibility change, or send a
pull request for a focused fix. Contributions are made under this repository's
GPL-3.0-only license and its SULFUR/Unity linking permission.

Keep game binaries, decompiled game source, save files, personal configuration,
tokens and logs out of commits. Reference your own installed game when building.
Avoid renaming the legacy plugin GUID or save unlock key without a migration.

Run `Test.ps1` and `Build.ps1`. For UI or scene changes, also test in the church:
placement, repeated interaction, Escape/cursor behavior, chest quantities,
gray recipes, expansion, filtering, sorting and scrolling. Describe the game
build and validation in your pull request. Attach screenshots for visual changes.

Distributed forks must preserve GPL licensing and provide their corresponding
source. Mark modified releases clearly and retain attribution to zbaloc.
